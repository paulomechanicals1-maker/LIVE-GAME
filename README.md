
# LIVE BRAWL

Um jogo de luta 2D em desenvolvimento, criado com Python e Pygame.

## Objetivo

Desenvolver uma experiência de combate vertical para TikTok LIVE, na qual os presentes enviados pelos espectadores poderão ativar ataques e poderes dentro do jogo.

## Tecnologias

- Python 3.12
- Pygame 2.6.1

## Estado atual

- [x] Janela do jogo
- [x] Interface vertical 9:16
- [x] Arena inicial
- [ ] Gravidade e colisões
- [ ] Movimentação dos lutadores
- [ ] Sistema de combate
- [ ] Integração com TikTok LIVE

## Como executar

1. Instale o Python.
2. Instale o Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Execute:

   ```bash
   python main.py
   ```

## Projeto em desenvolvimento

LIVE BRAWL é um projeto independente, com a intenção de desenvolver personagens, mecânicas e identidade visual originais.
